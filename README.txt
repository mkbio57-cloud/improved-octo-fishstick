Features in this starter:
- Login
- Dashboard
- Inventory
- Add medicine
- Billing
- Stock deduction
- Sales history
- Offline SQLite database

For a production pharmacy application, add batch/expiry, supplier, purchase,
returns, GST/HSN, prescription controls, barcode and printer integration.
